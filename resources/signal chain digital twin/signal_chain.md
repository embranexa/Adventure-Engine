Adventure Engine = Processing Chain

1. sensorium / excavator: flux -> prima materia (raw)
- crawler/scraper

2. augur/nexus/centrifuge: prima materia -> ore (potential)
- extract signal from noise
- discovery mode
- atlas, calendar

3. refiner: ore -> essence
- assign mappings
- centrifuge
- codex
- event forge

4. alembic: essence -> distillate (atomic actions)
- decomposite adventure into atomic actions

5. crucible: distillate -> alloy
- begin building actions
- quest log

6. arena: alloy -> animus

7. treasury: animus -> artifact

8. archive: artifact -> relic

trash: storehouse for ignored events
necropolis / graveyard: storehouse for dead adventures

- sync crawlers
- navigate between modules
- analytics; filter by { source, type, city, etc }

* entropy market
- cash in credits
